## Модель безопасности OHMAMI

Этот документ описывает основные принципы безопасности в системе OHMAMI.

### Ключевые принципы

- **Прозрачность** — пользователь понимает, какие данные собираются и передаются.
- **Минимизация** — собираются только те данные, которые необходимы для работы функции.
- **Защита каналов** — шифрование трафика между устройствами (TLS/DTLS и др., по факту реализации).

### Уровни доверия

- **Телефон пользователя** — источник данных и точка, где хранятся личные данные.
- **ПК‑агент** — доверенное приложение на компьютере пользователя.
- **Сервер** (если есть) — промежуточное звено, которое не должно иметь лишнего доступа к содержимому.

### Управление доступом

- Разрешения Android (доступ к файлам, уведомлениям, экрану).
- Локальная аутентификация/авторизация в приложении.
- Маркеры сессий и ключи доступа между компонентами системы.

Точные детали реализации (какие алгоритмы, какой режим TLS и т.п.) следует зафиксировать здесь по мере внедрения.
