## HTTP API агента OHMAMI

Этот документ описывает HTTP‑эндпоинты агент-приложения на ПК.

> Примечание: конкретные URL и схемы запросов/ответов стоит синхронизировать с реальной реализацией.

### Базовая информация

- **Базовый URL**: `http://<host>:<port>/api`
- **Аутентификация**: токен/ключ сессии (уточнить механизм).

### Примеры эндпоинтов

- `GET /device` — получить информацию о подключённом устройстве.
- `GET /files` — список файлов/каталогов.
- `POST /files/upload` — загрузка файла на устройство.
- `POST /media/control` — управление мультимедиа (play/pause/next и т.п.).

Каждый эндпоинт в дальнейшем можно задокументировать в формате:

- **Метод и путь**
- **Параметры запроса**
- **Тело запроса**
- **Ответ (успех/ошибка)**
