## WebSocket протокол OHMAMI

Этот документ описывает протокол взаимодействия по WebSocket между мобильным приложением, агентом и, при необходимости, сервером.

### Подключение

- **URL**: `ws://<host>:<port>/ws`
- Аутентификация при подключении: токен в query‑параметре или заголовке (уточнить реализацию).

### Формат сообщений

Обычно используется JSON‑формат, например:

```json
{
  "type": "event",
  "event": "device_connected",
  "payload": {
    "deviceId": "123",
    "model": "Pixel 7"
  }
}
```

### Типы сообщений

- **События устройства**: `device_connected`, `device_disconnected`, изменение состояния батареи/сети и т.п.
- **Команды управления**: запросы на выполнение действий (управление медиа, стриминг, операции с файлами).
- **Системные сообщения**: ping/pong, ошибки протокола.

Детализацию типов сообщений и схемы payload можно оформить отдельной таблицей или JSON‑схемами.
