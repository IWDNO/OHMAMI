# Обзор системы OHMAMI

OHMAMI — это система удалённого управления компьютером с мобильного устройства. Она позволяет управлять файлами, приложениями, медиа, системными настройками и даже транслировать экран ПК прямо с вашего Android-устройства.

## Что такое OHMAMI?

OHMAMI состоит из двух основных компонентов:

1. **Мобильное приложение** (Flutter/Android) — клиент на вашем телефоне
2. **Агент-приложение** (.NET/Windows) — серверная часть на вашем ПК

Оба компонента работают в локальной сети и не требуют внешних серверов или интернет-соединения для базовой функциональности.

## Основные возможности

| Функция | Описание |
|---------|----------|
| **Управление файлами** | Просмотр, загрузка, скачивание файлов с ПК |
| **Управление приложениями** | Запуск и блокировка приложений на ПК |
| **Управление медиа** | Контроль воспроизведения музыки/видео, регулировка громкости |
| **Системное управление** | Выключение, перезагрузка, режим сна/гибернации |
| **Мониторинг системы** | Отслеживание метрик CPU, GPU, памяти, сети в реальном времени |
| **Стриминг экрана** | Трансляция экрана ПК на мобильное устройство |
| **Безопасность** | Блокировка приложений, файлов и веб-сайтов |

## Архитектура системы

![Архитектура системы OHMAMI](../images/System%20architecture.png)

### Компоненты

#### Мобильное приложение

- **Технологии**: Flutter, Dart
- **Платформа**: Android 5.0+
- **Функции**:
  - Автоматический поиск агентов в локальной сети (mDNS)
  - HTTP API для управления системой
  - WebSocket для получения метрик в реальном времени
  - Стриминг экрана через Agora RTC

#### Агент на ПК

- **Технологии**: .NET 8.0, ASP.NET Core
- **Платформа**: Windows 10/11
- **Функции**:
  - HTTP REST API для управления системой
  - WebSocket сервер для передачи метрик
  - Интеграция с Windows API для управления системой
  - Блокировка процессов и файлов через ACL

## Типичные сценарии использования

### Домашний офис

- Управление медиа-плеером на ПК во время работы
- Мониторинг загрузки системы во время рендеринга
- Быстрый доступ к файлам на рабочем ПК

### Игровая комната

- Управление музыкой во время игры
- Мониторинг температуры и производительности
- Удалённое выключение ПК

### Родительский контроль

- Блокировка нежелательных приложений
- Блокировка веб-сайтов через файл hosts
- Мониторинг активности системы

### Удалённая работа

- Доступ к файлам на домашнем ПК
- Управление задачами и приложениями
- Стриминг экрана для демонстрации

## Преимущества

✅ **Локальная работа** — не требует интернета для базовой функциональности  
✅ **Быстрая установка** — простая настройка за несколько минут  
✅ **Безопасность** — все данные остаются в локальной сети  
✅ **Открытый исходный код** — полный контроль над системой  
✅ **Бесплатно** — нет подписок или скрытых платежей  

## Ограничения

⚠️ **Только Windows** — агент работает только на Windows 10/11  
⚠️ **Локальная сеть** — требуется подключение к одной сети (или VPN)  
⚠️ **Нет шифрования** — в текущей версии трафик не шифруется (используйте только в доверенных сетях)  
⚠️ **Нет аутентификации** — любой в сети может подключиться (настройте брандмауэр)

> **Примечание**: Планируемые функции ~~облачного хранения~~ и ~~удалённого доступа через интернет~~ пока не реализованы. Текущая версия работает только в локальной сети.
