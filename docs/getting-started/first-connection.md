# Первое подключение телефона к ПК

Этот документ описывает процесс первого подключения мобильного приложения OHMAMI к агенту на ПК.

## Предварительные условия

Перед подключением убедитесь, что:

- [ ] Мобильное приложение OHMAMI установлено и запущено на телефоне
- [ ] Агент OHMAMI установлен и запущен на ПК
- [ ] Оба устройства подключены к одной локальной сети (Wi-Fi)
- [ ] Брандмауэр Windows разрешает входящие соединения на порт 5000

> **Важно**: Для первого подключения рекомендуется использовать локальную Wi-Fi сеть, а не мобильный интернет.

## Способы подключения

### Способ 1: Автоматический поиск (рекомендуется)

Приложение OHMAMI автоматически ищет агенты в локальной сети при запуске.

1. Запустите приложение OHMAMI на телефоне
2. Дождитесь завершения автоматического поиска (обычно занимает несколько секунд)
3. Если агент найден, его адрес автоматически появится в поле ввода
4. Нажмите кнопку **"Подключиться"** или **"Ping"** для проверки соединения
5. После успешного подключения WebSocket приложение автоматически перейдёт на главный экран

> **Примечание**: Автоматический поиск использует протокол mDNS (Multicast DNS) для обнаружения агентов в локальной сети.

### Способ 2: Ручной ввод IP-адреса

Если автоматический поиск не нашёл агент, вы можете ввести IP-адрес вручную.

#### Шаг 1: Узнайте IP-адрес ПК

**В Windows:**

1. Откройте командную строку (Win + R, введите `cmd`)
2. Выполните команду:
   ```bash
   ipconfig
   ```
3. Найдите IP-адрес в разделе "Адаптер беспроводной локальной сети" или "Ethernet адаптер"
4. Запишите IPv4-адрес (например, `192.168.1.100`)

**Альтернативный способ:**

1. Откройте "Параметры" → "Сеть и Интернет" → "Wi-Fi" (или "Ethernet")
2. Нажмите на активное подключение
3. Найдите значение "IPv4-адрес"

#### Шаг 2: Введите адрес в приложении

1. Откройте приложение OHMAMI
2. В поле ввода введите адрес в формате: `http://<IP-адрес>:5000`
   - Например: `http://192.168.1.100:5000`
3. Нажмите кнопку **"Ping"** для проверки доступности агента
4. Если ping успешен, нажмите **"Подключиться"** для установления WebSocket соединения
5. После успешного подключения приложение перейдёт на главный экран

## Проверка подключения

После подключения проверьте следующее:

### В мобильном приложении

- ✅ Статус подключения показывает "Connected" или "Подключено"
- ✅ Отображается главный экран с кнопками навигации
- ✅ Метрики системы обновляются в реальном времени (если включены уведомления)

### На ПК (в консоли агента)

- ✅ Появляется сообщение: `WebSocket connected. Total clients: 1`
- ✅ Нет ошибок в логах

### Функциональная проверка

Попробуйте выполнить базовые действия:

1. **Проверка метрик**: Откройте раздел "Система" и убедитесь, что отображаются данные о CPU, памяти и т.д.
2. **Управление медиа**: Откройте раздел "Мультимедиа" и попробуйте управлять воспроизведением
3. **Проводник файлов**: Откройте раздел "Проводник" и проверьте доступ к файлам

## Решение проблем

### Агент не найден автоматически

**Возможные причины:**

- Агент не запущен на ПК
- Устройства в разных сетях
- Брандмауэр блокирует mDNS трафик
- Порт 5000 заблокирован

**Решение:**

1. Убедитесь, что агент запущен (проверьте консоль или процессы Windows)
2. Проверьте, что оба устройства в одной Wi-Fi сети
3. Попробуйте подключиться вручную по IP-адресу

### Ping не проходит

**Возможные причины:**

- Неверный IP-адрес
- Агент не запущен
- Брандмауэр блокирует соединение
- Порт занят другим приложением

**Решение:**

1. Проверьте IP-адрес ПК ещё раз
2. Убедитесь, что агент запущен и отвечает на `http://localhost:5000/ping`
3. Настройте брандмауэр Windows:
   - Откройте "Брандмауэр Защитника Windows"
   - Нажмите "Разрешить работу с приложением"
   - Найдите "OhmamiAgent" и разрешите входящие соединения
4. Проверьте, что порт 5000 не занят:
   ```bash
   netstat -ano | findstr :5000
   ```

### WebSocket не подключается

**Возможные причины:**

- Брандмауэр блокирует WebSocket соединения
- Неверный формат URL (должен быть `http://`, не `ws://`)
- Проблемы с сетью

**Решение:**

1. Убедитесь, что URL начинается с `http://` (приложение автоматически преобразует его в `ws://` для WebSocket)
2. Проверьте настройки брандмауэра (см. выше)
3. Попробуйте перезапустить агент и приложение

### Приложение зависает при подключении

**Решение:**

1. Закройте приложение полностью
2. Перезапустите агент на ПК
3. Откройте приложение заново и попробуйте подключиться

## Дополнительные настройки

### Настройка брандмауэра Windows

Для постоянной работы рекомендуется настроить правило брандмауэра:

1. Откройте "Брандмауэр Защитника Windows с расширенными параметрами"
2. Создайте новое правило для входящих соединений:
   - Тип: Порт
   - Протокол: TCP
   - Порт: 5000
   - Действие: Разрешить подключение
   - Профили: Доменный, Частный, Публичный

### Использование через VPN

Если устройства в разных сетях, можно использовать VPN:

1. Настройте VPN-сервер на ПК или используйте сторонний VPN-сервис
2. Подключите оба устройства к VPN
3. Используйте VPN IP-адрес для подключения

> **Предупреждение**: При использовании через интернет убедитесь, что VPN использует шифрование, так как OHMAMI в текущей версии не шифрует трафик.
