# Установка OHMAMI

В этом документе описывается установка всех компонентов системы OHMAMI: мобильного приложения и агент-приложения на ПК.

> **Важно**: Для полноценной работы системы необходимо установить оба компонента.

## Установка мобильного приложения

### Требования

| Параметр | Значение |
|----------|----------|
| **Платформа** | Android 5.0 (API 21) и выше |
| **Интернет-соединение** | Требуется для первого запуска |
| **Разрешения** | Доступ к файлам, уведомлениям, экрану |

### Сборка из исходников

1. Установите [Flutter SDK](https://flutter.dev/docs/get-started/install) версии 3.9.2 или выше
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-org/OHMAMI.git
   cd OHMAMI/ohmami_app
   ```
3. Установите зависимости:
   ```bash
   flutter pub get
   ```
4. Соберите и установите:
   ```bash
   flutter run
   ```
   Или создайте APK:
   ```bash
   flutter build apk --release
   ```

### Первичный запуск

1. Запустите приложение **OHMAMI**
2. Предоставьте необходимые разрешения
3. Убедитесь, что устройство подключено к той же сети, что и ПК-агент

## Установка агент-приложения на ПК

### Требования

| Параметр | Значение |
|----------|----------|
| **ОС** | Windows 10/11 (64-bit) |
| **.NET Runtime** | .NET 8.0 или выше |
| **Права доступа** | Обычные права (для некоторых функций — администратор) |
| **Сеть** | Открытый порт 5000 для HTTP и WebSocket |

### Сборка из исходников

1. Установите [.NET SDK 8.0](https://dotnet.microsoft.com/download) или выше
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-org/OHMAMI.git
   cd OHMAMI/agent/OhmamiAgent
   ```
3. Восстановите зависимости:
   ```bash
   dotnet restore
   ```
4. Соберите проект:
   ```bash
   dotnet build --configuration Release
   ```
5. Запустите агент:
   ```bash
   dotnet run --configuration Release
   ```

### Конфигурация

Агент использует файл `appsettings.json` для настройки:

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `MetricsIntervalSeconds` | Интервал отправки метрик (секунды) | 2 |
| `MediaIntervalSeconds` | Интервал обновления медиа (секунды) | 3 |
| Порт HTTP | Порт для HTTP API | 5000 |

> **Важно**: Убедитесь, что брандмауэр Windows не блокирует входящие соединения на порту 5000.

### Проверка запуска

Проверьте доступность API:
```bash
curl http://localhost:5000/ping
```

Ожидаемый ответ:
```json
{
  "status": "ok",
  "msg": "agent alive"
}
```

## Проверка установки

- [ ] Мобильное приложение запускается без ошибок
- [ ] Агент запущен и отвечает на `/ping`
- [ ] Оба устройства в одной сети

## Решение проблем

**Мобильное приложение не запускается:**
- Проверьте версию Android (5.0+)
- Убедитесь, что зависимости установлены: `flutter pub get`

**Агент не запускается:**
- Проверьте установку .NET Runtime 8.0+
- Убедитесь, что порт 5000 не занят

**Не удаётся подключиться:**
- Убедитесь, что оба устройства в одной сети
- Проверьте настройки брандмауэра Windows
