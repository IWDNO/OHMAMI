## Управление мультимедиа

Раздел управления мультимедиа позволяет с ПК управлять воспроизведением аудио и видео на подключённом телефоне.

### Основные функции

- Просмотр текущего трека/видео.
- Пауза, воспроизведение, переключение треков.
- Регулировка громкости (если поддерживается).
- Переключение источника (локальный плеер, стриминговые сервисы — по факту поддерживаемых клиентов).

### UI-элементы

- Панель с обложкой трека/видео.
- Кнопки «Play/Pause», «Next/Prev».
- Индикатор прогресса и времени.

Некоторые приложения могут ограничивать внешнее управление мультимедиа — это зависит от политики конкретного плеера и версии ОС.
