## Проводник файлов

Проводник файлов позволяет просматривать и управлять файлами на подключённом телефоне прямо с ПК.

### Возможности

- Просмотр структуры каталогов устройства.
- Загрузка файлов с телефона на ПК.
- Загрузка файлов с ПК на телефон (если реализовано).
- Удаление и переименование файлов (в рамках доступных разрешений).

### Интерфейс

- **Левая панель** — дерево каталогов.
- **Правая панель** — список файлов в выбранной папке.
- **Панель действий** — кнопки «Скачать», «Загрузить», «Удалить» и др.

Обрати внимание на ограничения ОС и разрешений Android: некоторые системные директории могут быть недоступны.
